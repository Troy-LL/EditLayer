# Storefront example

A stand-in for **your own** React + Vite app: ordinary components, real CSS, one `editlayer()` line in `vite.config.js`.

```bash
npm install && npm run dev
```

Open [http://127.0.0.1:5180](http://127.0.0.1:5180) and press **E** to toggle the EditLayer overlay.

The overlay talks to the EditLayer server on port **3001**. From the repo root:

```bash
cd server && npm run dev
```

Edit `editlayer.brief.md` in this folder (or from the overlay) so agents know how this project should look and feel.
