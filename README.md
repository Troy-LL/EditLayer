# EditLayer

Drop-in visual editor for a React app. Toggle edit, drag and restyle, save to a database.

The layout is JSON. A person can drag it. A model can write the same file.

## Run

```bash
cd server && npm install && npm run dev
```

```bash
cd client && npm install && npm run dev
```

Spec, design, architecture, and API notes live under [docs/](docs/). Original ideation is a snapshot at [docs/notes/my-idea.md](docs/notes/my-idea.md).
